4 · Distributed pipeline — Blackbird's Kafka

How the real system scales: pushes become Kafka messages; a crawler produces one message per document into a topic partitioned by content hash; each shard consumes exactly one partition and builds its own index. Queries never touch Kafka — they fan out synchronously to every shard and merge. Dots below are events from a real broker run of kafka-demo (spec 003).
