The documentation taxonomy for this repo:

- **[spec/](../spec/README.md)** — *what* to build (numbered, requirement IDs,
  the source of truth)
- **docs/** — *how* it's built (architecture, maps from intent to code)
- **[CLAUDE.md](../CLAUDE.md)** — *how we work* (commands, hard rules, agent
  workflow)

A change is complete when all three still agree with the code.
